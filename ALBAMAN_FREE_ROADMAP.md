# Albaman AI — дорожная карта с обязательной стоимостью $0

**Дата:** 24 августа 2026 года  
**Git-ветка:** `feat/albamen-free-mode`  
**Последний базовый коммит:** `a7f4367`

## Главный вывод

При условии, что Albaman AI должен работать полностью бесплатно, **Azure OpenAI нельзя делать основным LLM в production**. Azure OpenAI тарифицируется по токенам, а временный Azure-кредит не превращает сервис в постоянный бесплатный. В аккаунте отображается кредит `$200`, срок действия — до **23 сентября 2026 года**; это окно для тестов, но не бесплатная модель эксплуатации.

Translator по прямому решению владельца **полностью исключён** из Albaman AI. Текущий бесплатный production-контур остаётся таким:

```text
Frontend AlbaSpace
        ↓
Cloudflare Worker divine-flower-a0ae
        ├── Groq Llama 3.3 70B — основной текстовый LLM
        ├── Cloudflare Workers AI — fallback и текущий голосовой контур
        ├── Cloudflare KV — память сессий и rate limits
        └── Telegram — включённое логирование диалогов по решению владельца
```

Azure OpenAI, Azure Speech, Azure AI Search и Azure AI Content Safety не включаются автоматически. Их можно рассматривать только как отдельные контролируемые эксперименты с лимитами и отключателем. Если требование `$0` означает также запрет использования временного Azure-кредита, эти функции не следует подключать вообще.

## Варианты эксплуатации

| Подход | Стоимость | Плюсы | Ограничения |
|---|---:|---|---|
| **Cloudflare + Groq + Workers AI + KV** | $0 при соблюдении бесплатных лимитов провайдеров | Сохраняет текущую скорость, API и существующий голосовой сценарий | Есть rate limits; качество зависит от Groq; Workers AI ограничен дневной бесплатной квотой |
| **Azure Speech F0 как ограниченный pilot** | $0 только в пределах бесплатной квоты или временного кредита | Можно проверить качество STT/TTS на реальных голосовых сценариях | Нужен отдельный учёт минут и явное выключение после лимита; не гарантирует бесконечную бесплатность |
| **Azure AI Content Safety F0 как ограниченный pilot** | $0 только в пределах free-tier | Полезно для детского режима и проверки опасных входов/ответов | F0 имеет ограничение объёма; после лимита нельзя молча переходить на платный tier |
| **Azure AI Search Free для небольшой RAG-базы** | $0 только при использовании Free service | Можно вынести знания из огромного system prompt | Shared resources, отсутствие масштабирования, ограничение на один Free Search service и возможное удаление после неактивности |
| **Azure OpenAI на временном кредите** | $0 только до исчерпания кредита/срока | Можно провести controlled benchmark разных моделей | Не является постоянным бесплатным production-решением |
| **Локальная open-source модель** | $0 за API при наличии собственного компьютера | Нет оплаты за токены | Нужны компьютер, постоянный доступ и обслуживание; Cloudflare Worker сам модель не запустит |

## Что уже реализовано

В отдельной ветке `feat/albamen-free-mode` обновлён AI-worker. Production автоматически не заменён.

Worker ограничивает CORS доменами AlbaSpace вместо `*`, нормализует языки до `ru`, `tr`, `en`, ограничивает размер текстовых и голосовых запросов, добавляет отдельный rate limit для голоса, защищает обработку повреждённой KV-памяти и возвращает явный `404` для удалённого `/api/translate`.

Telegram-логирование снова включено по умолчанию, если присутствуют `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`. Отключить его можно только явной настройкой `TELEGRAM_LOGGING_ENABLED=false`.

Код не содержит `AZURE_OPENAI_*`, не содержит Translator secrets и не имеет скрытого Azure fallback. Платная подписка Azure не включается автоматически.

## Azure-функции, которые можно рассмотреть позже

**Azure Speech.** Официальная страница цен указывает F0-квоту 5 аудиочасов в месяц для некоторых Speech-to-Text режимов [3]. Это может быть полезно для controlled pilot, но текущий бесплатный voice-flow на Workers AI лучше не ломать до сравнения качества, задержки и квоты TTS.

**Azure AI Content Safety.** Бесплатный режим указывает 5 000 текстовых записей и 5 000 изображений в месяц [4]. Для детского продукта это наиболее логичный Azure-кандидат, но Worker должен считать запросы и прекращать вызовы после лимита. До подключения нужна отдельная реализация локального budget guard.

**Azure AI Search Free.** Бесплатный Search service предназначен для небольших проектов и разработки; он shared, не масштабируется, некоторые функции недоступны, а один subscription может иметь только один Free Search service [5]. Такой слой может уменьшить system prompt, но его нужно добавлять только после проверки доступности Free SKU в конкретном регионе.

**Azure OpenAI.** Остаётся экспериментальным направлением только на временном кредите. Для режима постоянного `$0` он исключён.

### P0 — уже подготовлено к внедрению

У AI-панели добавлены быстрые кнопки сценариев: вопрос о планете, факт о космосе, загадка и книга. Добавлены понятные aria-подписи для кнопок, Enter-to-send, disabled-состояние во время запроса, индикатор «Альбамен думает», повтор запроса после ошибки, копирование ответа и кнопка нового диалога.

### P1 — текущая очередь улучшений

Нужно протестировать мобильный bottom-sheet/fullscreen, чтобы чат не перекрывал основной контент. Следует добавить ненавязчивую подсказку о микрофоне, состояние «слушаю», кнопку остановки записи и дружелюбное объяснение, если браузер не поддерживает Speech Recognition.

### P2 — развитие продукта

Следующий качественный шаг — тематические режимы «Планеты», «Космические миссии», «Книга Albamen и Lara» и «Загадки». Их можно реализовать через короткие preset-prompts без платных сервисов. После этого можно добавить локальную статическую RAG-базу в репозитории или KV, не используя Azure AI Search.

## Практический лимит $0

Cloudflare Workers AI сообщает о бесплатной квоте **10 000 Neurons в день** [1]. После превышения операции на бесплатном режиме могут завершаться ошибкой; graceful fallback и дружелюбное сообщение остаются обязательными.

Groq работает с ограничениями организации, измеряемыми RPM, RPD, TPM и другими показателями [2]. Бесплатность нельзя считать безлимитной: точные значения зависят от аккаунта и отображаются на странице Limits Groq. Worker не должен повторять запрос бесконечно после ответа `429`.

## Безопасный порядок следующих действий

Сначала проверить UI и новый Worker в preview environment. Затем вернуть production-конфиг с `TELEGRAM_LOGGING_ENABLED=true`, убедившись, что Cloudflare secrets уже существуют. После этого обновить production Worker отдельным подтверждённым deploy.

Azure Speech, Content Safety и AI Search не включать одновременно. Каждый эксперимент должен иметь собственный feature flag, квоту KV, graceful fallback и тест на отключение. Azure OpenAI не включать, если условие постоянного `$0` остаётся обязательным.
