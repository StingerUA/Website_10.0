# Browser check — AR restaurant menu

Дата проверки: 2026-08-26.

Страница `/ar-restaurant/` открылась локально в Chromium без ошибок навигации. Визуально отобразились тёмная glassmorphism-композиция, камера-заглушка, 3D-модель мясного блюда, информационная карточка, три категории, кнопка запуска AR и кнопка сброса позиции.

Переключение на категорию «Напитки» сработало без перезагрузки: заголовок изменился на `Citrus Spark`, описание и цена обновились, а загруженная модель сменилась на локальный `drink.glb`. Статическая проверка `node --check assets/js/restaurant-ar.js`, компиляция генератора GLB и проверка заголовков всех трёх GLB прошли успешно.

Ограничение smoke-теста: sandbox Chromium не даёт реальный видеопоток камеры по локальному URL без пользовательского разрешения, поэтому pinch-жест и MediaPipe проверяются кодом и требуют финального теста на HTTPS-домене с физической камерой.

Дополнительная проверка: справочный диалог открылся по кнопке `?`, содержит четыре шага и поясняет fallback. После загрузки и смены категории консоль Chromium не показала сообщений об ошибках.

Главная `/` также открылась штатно: новый блок `BROWSER AR EXPERIENCE` отображается между категориями и референсами, ссылка `/ar-restaurant/` присутствует. Существующее cookie-окно сайта осталось без изменений и визуально находится поверх главной, как предусмотрено текущей реализацией.

Автоматический DOM-тест подтвердил fallback-перетаскивание: позиция карточки изменилась с `left: 594px, top: 233.586px` на `left: 859px, top: 272.172px`, после клика reset вернулась в центр. Важно: `model-viewer` обновляет свойство `src` на `/assets/models/restaurant/drink.glb`, но не обязан синхронно отражать его в HTML-атрибуте; проверка свойства `viewer.src` показала правильный drink GLB, `viewer.loaded` — `true`.

Проверка кнопки «Включить AR» в sandbox завершилась ожидаемым fallback: статус сменился на `Камера не запущена`, а интерфейс предложил разрешить доступ или перетаскивать блюдо пальцем. В консоли присутствует только предупреждение `NotFoundError: Requested device not found`, без необработанной ошибки приложения.

Публичная проверка `https://albaspace.com.tr/ar-restaurant/` сразу после push дважды вернула стандартный GitHub Pages `404 File not found`, тогда как локальный сервер отдаёт страницу корректно. Это указывает на ещё не завершившийся или не обновившийся Pages deployment/CDN, а не на ошибку маршрута в репозитории. Следующий шаг — дождаться завершения workflow и повторить live-проверку.

После завершения workflow публичная проверка прошла: `https://albaspace.com.tr/ar-restaurant/` отдаёт HTTP 200 и визуально показывает опубликованный `AR Menu` с 3D-стейком, категориями, кнопками включения AR/reset и privacy note. GitHub Actions `Deploy static site to GitHub Pages` и `CI` для commit `56560e2` завершились успешно.

Проверка многоблюдной структуры: на старте отображается `1 / 2` и стейк. Клик по стрелке «вперёд» переключает на `2 / 2`, `Каре ягнёнка`, новую цену и описание; визуально загружена отдельная модель `lamb-chops.glb`. AR-контроллер и экранная композиция сохранились.

Обновлённый тест: при переходе в «Десерты» индекс сбрасывается на `1 / 2` и показывается `Трио мини-десертов`. Стрелка «вперёд» переключает на `2 / 2`, `Шоколадный торт`, цену `₺ 220` и отдельную модель `chocolate-cake.glb`. Счётчик, aria-label стрелок и status-подсказка обновляются.

Автоматический цикл напитков прошёл успешно: `Citrus Spark` (`1 / 2`, `drink.glb`) → `Alba Latte` (`2 / 2`, `latte.glb`) → циклический возврат к `Citrus Spark` (`1 / 2`). Позиция блюда остаётся центрированной после каждой смены, reset работает, консоль не показала новых ошибок.

После рефакторинга ручной drag fallback сохранился: текущий `Citrus Spark` переместился с `left: 594px, top: 233.586px` на `left: 871px, top: 272.172px`, затем reset вернул позицию в центр.

Live-проверка с `?v=2ff7b30` увидела новые стрелки и счётчик в HTML, но клик по live-стрелке пока не переключил блюдо. Причина — HTML обновился раньше закэшированного `/assets/js/restaurant-ar.js`, поэтому следующим исправлением добавлен version query к JS/CSS asset URL для гарантированного обновления CDN-кэша.
