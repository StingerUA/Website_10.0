# Albaman AI — проверка требования полного бесплатного режима

Дата: 24 августа 2026.

## Факты из Azure Portal

- В подписке `Azure subscription 1` доступен временный кредит `$200.00`.
- Кредит истекает `23 сентября 2026 года`; Azure Portal сообщает, что осталось 29 дней.
- Portal сообщает: бесплатные службы не тарифицируются, платные службы оплачиваются доступным кредитом; при окончании кредитов или истечении срока службы будут приостановлены.
- Portal просит перейти на подписку с оплатой по мере использования, но переход не выполнялся.
- На стартовой странице в последних ресурсах видны `albaspace-translator-2026` типа `Переводчик` и группа ресурсов `albaspace-translation-rg`.
- В просмотренных ресурсах нет подтверждения, что создан Azure OpenAI deployment. Поэтому ресурс, созданный вчера, по текущему виду — Azure Translator.

## Безопасный вывод

Нельзя обещать постоянную бесплатную работу Azure OpenAI: временный кредит $200 может покрывать платные вызовы только до 23.09.2026 или пока кредит не будет израсходован. Для строгого режима $0 Azure нельзя ставить в production primary/fallback без дополнительной проверки и лимитов.

## Практическая бесплатная стратегия

1. Cloudflare Worker остаётся production gateway.
2. Azure Translator можно использовать только при подтверждённой бесплатной квоте/кредите и с ограничением расходов; его разумная роль — перевод интерфейсных/учебных фраз, а не главный LLM.
3. Для AI-ответов сохранить текущий Groq + Cloudflare Workers AI, ограничить rate limit, сократить prompt и вынести знания в KV/статические файлы.
4. Azure OpenAI использовать только как отключаемый экспериментальный pilot, если пользователь сознательно разрешит расход временного Azure кредита. Не делать его обязательной частью бесплатного production-контура.
5. Cloudflare Workers AI предоставляет 10,000 Neurons/day бесплатно; после превышения без платного Workers plan дальнейшие операции завершаются ошибкой. Это означает, что бесплатный режим должен иметь жёсткий дневной лимит и graceful fallback.

## Подтверждение тарифа Translator

В Azure Portal у `albaspace-translator-2026` в разделе «Ценовая категория» выбран тариф `F0 Бесплатный`. Portal показывает квоту `2M` — до 2 миллионов переведённых символов в месяц. Это позволяет использовать Translator как бесплатный вспомогательный сервис в пределах лимита. Выбор тарифа не изменялся.

Практический вывод: созданный вчера ресурс Azure можно безопасно подключить к Albaman для переводов при сохранении F0. Azure OpenAI, Azure Speech, AI Search и Content Safety не следует считать постоянными бесплатными компонентами без отдельного подтверждения их бесплатной квоты.
