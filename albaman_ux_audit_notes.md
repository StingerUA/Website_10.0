# Albamen AI — UX-аудит

Дата: 24 августа 2026.

## Живая страница

Проверена русская страница https://albaspace.com.tr/rus/albamen.html. В шапке есть отдельная ссылка «AI ассистент». По нажатию открывается правый виджет шириной примерно 400 px поверх hero-блока.

- Кнопка fullscreen.
- Кнопка закрытия.
- Кнопка микрофона.
- Поле «Напишите сообщение...».
- Кнопка отправки.

## UX-проблемы и возможности

1. В пустом состоянии нет быстрых кнопок-сценариев: «Расскажи о космосе», «Покажи планеты», «Задай загадку», «Расскажи о книге». Для детского пользователя это повышает порог входа.
2. Не видно явного статуса `печатает`, `слушаю`, `обрабатываю`, `ошибка` и `повторить`. Нужны aria-live сообщения и визуальный индикатор.
3. Не видно подсказки о голосовом режиме и разрешении микрофона. Нужна короткая объясняющая подпись и понятное состояние записи.
4. Панель открывается поверх hero-контента; fullscreen должен перестраивать интерфейс, а не только менять размер.
5. Нужна отправка по Enter, перенос строки через Shift+Enter, автофокус и disabled-состояние отправки при пустом input.
6. Стоит добавить кнопку «Очистить разговор» и «Скопировать ответ», а также сохранить визуальное различие сообщений пользователя и Albamen.
7. Для детского UX полезны короткие ответы по умолчанию, быстрые карточки тем и дружелюбные, но не перегружающие emoji.
8. Мобильная версия должна использовать bottom sheet/почти full-screen chat, минимум 44 px touch targets и safe-area padding.

## Приоритетная бесплатная реализация

P0: Telegram logging включить обратно; Azure Translator удалить из Worker и конфигов; добавить UX-статусы, quick prompts, Enter-to-send, disabled send, retry и копирование.

P1: Улучшить чат-историю, очистку сессии, mobile fullscreen и доступность.

P2: Подключать Azure только через функции, для которых доказан бесплатный режим или которые запускаются локально/по кнопке; не делать Azure OpenAI обязательным маршрутом.

## Preview-проверка после UX-патча

В локальном preview после открытия панели видны локализованные controls: заголовок `Albamen AI`, зелёный online-индикатор, новая кнопка очистки диалога, fullscreen, закрытие, 4 quick actions, поле ввода и mic/send. Визуальный контраст статуса стал существенно лучше.

При текущем viewport панель визуально показывает верхнюю часть аватара; перед production deploy нужно дополнительно проверить, не обрезается ли изображение из-за flex-компоновки при загрузке и на мобильном viewport. Это проверяется следующим CSS-патчем через фиксированный размер avatar и `flex-shrink: 0`.
