# ALBAMEN digital book PDFs

The flipbook reader routes expect the production PDFs in this folder with these exact names:

- `albamen-and-lara-en.pdf`
- `albamen-and-lara-ru.pdf`
- `albamen-and-lara-tr.pdf`

Reader routes:

- `/en/book-albamen/`
- `/ru/book-albamen/`
- `/tr/book-albamen/`

The shared reader automatically splits landscape two-page PDF spreads into individual logical pages and keeps single-page/cover PDF pages intact.
