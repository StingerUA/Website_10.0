ALBASPACE GAME — RU PROTOTYPE v0.1
===================================

КУДА КОПИРОВАТЬ
---------------
В архиве уже есть структура:

game/
└── AlbaSpace/
    └── ru/
        ├── index.html
        ├── teacher.html
        ├── player.html
        ├── assets/
        │   ├── css/game.css
        │   └── js/
        │       ├── engine.js
        │       ├── teacher.js
        │       └── player.js
        └── data/questions.ru.json

Просто скопируй папку game/ в корень сайта/репозитория.
Если game/ уже существует — скопируй AlbaSpace/ru/ внутрь неё.

СТАРТОВАЯ СТРАНИЦА
------------------
/game/AlbaSpace/ru/index.html

ВАЖНО ПРО ЗАПУСК
----------------
questions.ru.json загружается через fetch(), поэтому не открывай HTML двойным кликом через file://.
Нужен обычный web server.

Если сайт уже опубликован через GitHub Pages — просто положи файлы в репозиторий.

Для локального теста из корня сайта:

python -m http.server 8080

После этого открой:
http://localhost:8080/game/AlbaSpace/ru/

ПЕРВЫЙ ПЛЕЙТЕСТ НА ОДНОМ КОМПЬЮТЕРЕ
-----------------------------------
1. Открой teacher.html в одной вкладке.
2. Создай комнату. Получишь 5-значный код.
3. Открой player.html в 2–6 НОВЫХ вкладках того же браузера.
4. В каждой введи код комнаты.
5. У каждого игрока:
   - введи уникальное название компании;
   - выбери 3 стартовых кадета.
6. На teacher.html нажми «Начать игру».
7. Учитель запускает вопрос.
8. Игроки отвечают.
9. Учитель раскрывает результат.
10. Учитель переводит игру в фазу станции.
11. Игроки принимают кадетов / покупают модуль.
12. Учитель запускает следующий вопрос.

ЧТО УЖЕ РАБОТАЕТ
----------------
- Комната и код входа.
- 2–10 игроков.
- Синхронизация вкладок одного браузера через BroadcastChannel/localStorage.
- 3 режима: Спринт / Стандарт / Обучение.
- Название компании.
- Выбор 3 стартовых кадетов.
- 5 тематик.
- NUMBER и TEXT вопросы.
- +10 кредитов за отправленный ответ.
- +30 кредитов победителю.
- +1 знание за правильный/достаточно близкий ответ.
- Ещё +1 знание победителю, если ответ подходит под допуск.
- Кадеты 0/4 → 4/4.
- Автоматическое обучение самого продвинутого кадета темы.
- Выпуск +350 кредитов.
- Повторяющиеся специализации кадетов.
- Малый модуль 650 / +2 места / максимум 7.
- Большой модуль 950 / +3 места / максимум 3.
- Старт: 1 большой + 1 малый модуль.
- Максимум одна покупка модуля за раунд.
- Победа: 7 малых + 3 больших = 10 модулей.
- Рейтинг.
- 25 тестовых русских вопросов.

ЧЕГО ПОКА НЕТ
-------------
- Настоящего backend.
- Игры между разными телефонами/компьютерами.
- Аккаунтов AlbaSpace.
- WebSocket.
- AR/MindAR.
- 3D станции.
- Паузы/reconnect.
- Учительской аналитики.
- Overtime / финального вопроса.
- Полной базы 88 физических карточек.

ЗАЧЕМ ЭТА ВЕРСИЯ
----------------
Это playable prototype для проверки главного игрового цикла:

вопрос → знания → кадеты → выпуск → кредиты → модули → 10/10.

Если этот цикл работает и нравится игрокам, следующим пакетом можно заменить локальную
синхронизацию настоящим backend/WebSocket и запустить игру между телефонами.

ВАЖНО
-----
Не используй BroadcastChannel/localStorage как production multiplayer.
Это только простой первый плейтест для одного компьютера/браузера.


ОБНОВЛЕНИЕ v0.1.1
-----------------
Исправлен критический баг поля ответа:
- поле больше не создаётся заново каждую секунду;
- набранные буквы/цифры не исчезают;
- при обновлениях от других вкладок текущий ввод сохраняется;
- отдельно обновляется только счётчик времени.

Таймеры ответа:
- Спринт: 60 / 65 / 70 / 75 секунд
- Стандарт: 75 / 80 / 90 / 100 секунд
- Обучение: 90 / 100 / 110 / 120 секунд

Даже в самом быстром режиме любой вопрос даёт минимум 60 секунд на размышление.
