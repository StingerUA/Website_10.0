# ALBAMEN Cosmos topic image slots

Each topic folder contains the shared image slots used by both Study Cards and Quiz.

Naming convention per topic:

- `01 F.webp` ... `10 F.webp` = front/question image
- `01 B.webp` ... `10 B.webp` = back/answer image

Study Cards and Quiz intentionally reuse the same F/B pair for the same topic/index.

You can replace any placeholder file manually later without changing JavaScript, as long as the filename stays the same.
