🔧 targets.mind Компилятор

Этот инструмент последовательно загружает все изображения из папки assets/models-pictures/ и создаёт файл targets.mind для MindAR.
Процесс компиляции может занять несколько минут. Не закрывайте вкладку браузера.

Инструкция по использованию
  1. Изображения ниже перечислены в правильном порядке (этот порядок должен совпадать с scanner/index.html).
  2. Нажмите кнопку «Запустить компиляцию» и дождитесь завершения процесса.
  3. По завершении появится кнопка «Скачать targets.mind». Скачайте файл.
  4. Скопируйте скачанный targets.mind в папку scanner/.
  5. Теперь AR-сканер готов к работе!
